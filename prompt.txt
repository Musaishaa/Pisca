Buatkan saya sebuah aplikasi web bernama PISCA (Personal Intelligent Study & Chat Assistant).

TUJUAN UTAMA

PISCA adalah chatbot AI generatif lokal/offline yang:

dapat menjawab pertanyaan pengguna,
dapat mengingat informasi yang diberikan pengguna,
dapat menggunakan memory tersebut pada percakapan berikutnya,
tidak menggunakan API cloud seperti OpenAI/Gemini,
pada tahap awal berjalan di laptop melalui web browser,
arsitekturnya harus disiapkan agar model AI yang sama nantinya dapat dioptimalkan dan dipindahkan ke aplikasi Android.

Saya hanya membutuhkan MVP yang benar-benar bisa berjalan, jangan membuat fitur berlebihan.

1. TEKNOLOGI

Gunakan:

Frontend

fokus tampilan seperti aplikasi chat

Local AI

Gunakan arsitektur Local LLM Adapter agar model AI dapat diganti tanpa mengubah seluruh aplikasi.

Untuk development awal, gunakan Ollama/local LLM sebagai runtime model lokal.

Jangan gunakan API berbayar atau layanan AI cloud.

Buat konfigurasi model melalui .env, misalnya:

LLM_PROVIDER=ollama
LLM_MODEL=<LOCAL_MODEL_NAME>
LLM_BASE_URL=http://localhost:11434

Jangan hard-code nama model di banyak file.

4. MEMORY SYSTEM

Ini fitur penting.

PISCA harus memiliki memory, tetapi jangan melatih ulang model setiap kali pengguna memberikan informasi.

Gunakan konsep:

LLM + Memory Database

Contoh:

User:

Nama saya Pisca.

PISCA:

Baik, saya akan mengingat bahwa nama Anda Pisca.

Simpan ke database:

category: personal
key: name
value: Pisca

Contoh lain:

User:

Saya mahasiswa Sistem Informasi.

Simpan:

category: education
key: major
value: Sistem Informasi

Kemudian user bertanya:

Siapa nama saya?

Sistem mengambil memory:

name = Pisca
major = Sistem Informasi

Lalu informasi tersebut dimasukkan ke context LLM agar model dapat menghasilkan jawaban.

9. AI GENERATIF

PISCA harus menggunakan LLM lokal untuk menghasilkan jawaban.

Alurnya:

User Question
      ↓
Chat Service
      ↓
Ambil relevant memory
      ↓
Bangun context
      ↓
Local LLM
      ↓
Generated Response
      ↓
User

Contoh prompt ke model:

SYSTEM:
You are PISCA, a local personal AI assistant.

USER MEMORY:
Name: Pisca
Occupation: Student
Major: Information Systems

USER QUESTION:
Siapa saya?

Respond naturally using the available memory.
Do not invent personal information that is not present in memory.

Model harus menghasilkan jawaban berdasarkan context yang diberikan.

10. ATURAN MEMORY DAN HALUSINASI

PISCA tidak boleh mengarang informasi pribadi.

Jika user bertanya:

Berapa umur saya?

dan memory tidak memilikinya, jawab:

Saya belum mengetahui umur Anda karena informasi tersebut belum pernah diberikan.

Jangan menebak.

Jika user memberikan informasi subjektif seperti:

Pisca adalah mahasiswa tercantik.

Boleh disimpan sebagai:

category: user_statement
key: statement
value: Pisca adalah mahasiswa tercantik.
source: user

Kemudian PISCA harus menjelaskan bahwa itu adalah informasi yang diberikan pengguna, bukan fakta yang diverifikasi.
